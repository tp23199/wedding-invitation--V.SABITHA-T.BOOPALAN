Wedding Invitation Website
Open index.html in a modern browser.

The invitation video is configured to play with sound. The background wedding song starts when the invitation is opened. Some browsers block sound autoplay; if so, tap the on-screen play button once.

The website includes English invitation text, Tamil bride and groom names, a scratch-to-reveal wedding date, and a live countdown.


Updated version:
- Intro video attempts autoplay with sound; if the browser blocks audible autoplay, it continues muted.
- Tap anywhere on the intro screen once to enable video sound (no separate play button).
- After OPEN INVITATION is pressed, the supplied MP3 starts and loops throughout the invitation.
- Responsive layout optimized for mobile and desktop.
Note: Browsers (especially iPhone/Safari and Android Chrome) may block sound autoplay until a user gesture. This is a browser security policy and cannot be bypassed by website code.
